source <record> <view> accepts body, fold, json or fields. A selected record’s contact annotation shows the decoded span and the exact raw JSON contribution.
map-span <record> <space> <start-end> accepts bytes, utf16, scalars or json (raw JSON bytes). Ranges are zero-based and end-exclusive. An edge inside an escape or surrogate pair cannot be translated to a scalar boundary.
json-check accepts a flat object of strings or the samples literal, paired, lone, duplicate, doubled and decomposed. Paste JSON unchanged in the argument editor.
