COLLISION QUERY / OPERATOR NOTES

The diagnostic accepts a candidate spelling of the displayed name. Requests for the ordinary lookup key are blocked. A distinct spelling with a matching similarity key locates the bucket. The diagnostic does not return the source names.

Once the bucket is located, reconstruct both names using the audit evidence. The ownership check compares the original spelling against each independently verified source record. An accepted query spelling is not evidence of an original.

Inspect a character from the audit display name to see related scalars, scripts and encodings.
