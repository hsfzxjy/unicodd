extract takes a named target or all, and a mapping. Try raw, nfc, lower, nfkc or ascii to see the effects of transforming original names. probe-path shows the parsed components and comparison keys for one trial.
The receiver can read original Unicode names from the manifest. The physical paths use bounded ASCII letters, digits, hyphens, underscores and dots in slash-separated components. Use id for stable file ID handles, prefix:<directory> for a relative folder of those handles, or map:<file-id>=<path>,... to supply every path. bind:<file-id>=<payload-id>@<path>,... lets you check a transferred table with separate source and payload columns.
roundtrip opens the staged manifest on all targets and verifies file identity and public payload, including byte-identical assets with distinct source files.
